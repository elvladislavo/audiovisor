Bolt

A robot assembled from rounded boxes and capsules. Each limb hangs off a named joint group, and every clip is a set of rotation keyframes on those joints.

How a clip is written

// one track per joint, Euler keys → quaternions
rot('hipL',  T, [[-.5,0,0],[0,0,0],[.5,0,0],…]),
rot('kneeL', T, [[.1,0,0],[.15,0,0],…,[.95,0,0]]),
// switch with a 0.35 s crossfade
next.reset().play();
current.crossFadeTo(next, 0.35, true);

Kelp

Tapered cylinders bound to a chain of bones. Each vertex is weighted to the two nearest bones, and every frame a sine wave bends the chain, so the mesh flexes smoothly instead of hinging.

How the skin is weighted

// vertex at height y → bones b and b+1
const b = Math.floor(y / segH);
const w = (y - b * segH) / segH;
skinIndex.push(b, b + 1, 0, 0);
skinWeight.push(1 - w, w, 0, 0);
// per frame
bone.rotation.z = sway * Math.sin(t - i * ripple);
