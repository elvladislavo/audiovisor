Откройте `index.html`: на нём пять вариантов дизайна.

## Как добавить свои фото

1. Положите исходники (JPG, PNG или HEIC прямо с телефона, в полном размере) в `photos/originals/`.
2. Назовите каждый файл с префиксом категории: `torty-`, `dekor-`, `usadba-`, `priroda-` или `eda-`.
   Например: `torty-svadebnyj-belyj.jpg`, `priroda-cvetenie-maj.jpg`.
3. Запустите:
   ```
   pip install pillow pillow-heif     # один раз
   python3 tools/optimize_photos.py
   ```
4. Всё. Галерея и фильтры по категориям обновятся сами.

Скрипт поворачивает фото по EXIF и удаляет метаданные (включая геометки).
Цвет переводится в sRGB. Скрипт режет фото на 480/960/1600/2400 px и никогда
не увеличивает их. Каждая ширина сохраняется в AVIF, WebP и JPEG. Браузер сам
берёт самый лёгкий формат и нужный размер. Пока фото грузится, видно размытое превью.

Сейчас в `photos/originals/` лежат временные фото: они вырезаны из скриншота Instagram и потому маленькие.
